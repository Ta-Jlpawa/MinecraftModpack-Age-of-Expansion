# 空间IO端口

<BlockImage id="spatial_io_port" p:powered="true" scale="8" />

空间IO端口用于[空间储存](../ae2-mechanics/spatial-io.md)，用来容纳[空间存储元件](spatial_cells.md)
并控制空间储存操作。

如果你想自动化这一过程，元件可以通过漏斗或 ae2 总线等任意物品物流方式插入和取出。
