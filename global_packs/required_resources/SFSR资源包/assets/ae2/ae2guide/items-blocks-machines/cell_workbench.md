# 元件工作台

<BlockImage id="cell_workbench" scale="8" />

元件工作台用于配置[存储元件](storage_cells.md)和 <ItemLink id="view_cell" />。

你可以添加[升级卡](upgrade_cards.md)，并配置"分区"以过滤存储元件将要存储的内容。

即使你手上没有某个物品，也可以直接从 JEI/REI 将物品或流体拖入槽位。

右键点击流体容器（如桶或流体储罐）即可将该流体设为过滤器，而不是放入桶或储罐物品本身。

## 设置

元件工作台的左上角有几个按钮：

*   可以根据存储元件当前的已有内容为其建立分区
*   可以清除存储元件的分区设置
*   工作台可设置为在取出存储元件后保留分区设置，方便你在多个存储元件之间复制设置。
