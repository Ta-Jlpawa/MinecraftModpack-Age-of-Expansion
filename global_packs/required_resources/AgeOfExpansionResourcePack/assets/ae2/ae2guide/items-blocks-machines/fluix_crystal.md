# 福鲁伊克斯水晶

<ItemImage id="fluix_crystal" scale="4" />

*"福鲁伊克斯水晶拥有独特的能力：吸收能量并将其从一种形式转化为另一种形式，它是一切物质能量技术的基石。"*

它是 AE2 方块、[设备](../ae2-mechanics/devices.md)和物品的主要原材料之一。将下界石英、红石和 <ItemLink id="charged_certus_quartz_crystal" /> 丢入水中制成。

可以利用 <ItemLink id="formation_plane" /> 和 <ItemLink id="annihilation_plane" /> 来[自动化](../example-setups/throw-in-water-automation.md)生产。
