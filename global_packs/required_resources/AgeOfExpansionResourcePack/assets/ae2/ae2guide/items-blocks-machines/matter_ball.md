# 物质球

<ItemImage id="matter_ball" scale="4" />

一团普通物质，可用作<ItemLink id="matter_cannon" />的弹药，或用于制作[涂料球](paintballs.md)。

在物质球模式下的<ItemLink id="condenser" />中用256个物品或桶制成。
