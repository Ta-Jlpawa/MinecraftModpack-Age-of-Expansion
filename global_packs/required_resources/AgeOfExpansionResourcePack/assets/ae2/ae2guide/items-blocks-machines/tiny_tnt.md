# 微型TNT

<BlockImage id="tiny_tnt" scale="8" />

用于小型爆炸的小型 TNT。适合用来制作<ItemLink id="quantum_entangled_singularity" />（量子纠缠奇点）对。

如果你想在服务器上禁用 TNT 和苦力怕，可以在配置中关闭它的方块破坏能力，从而在不造成破坏的前提下制作奇点。
