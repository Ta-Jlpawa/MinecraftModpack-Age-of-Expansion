# 视界元件

<ItemImage id="view_cell" scale="2" />

视界元件用于过滤[终端](terminals.md)的显示内容。你需要在<ItemLink id="cell_workbench" />中对它们进行分区。

举例来说，假如你想让某个终端只显示一部分石头类建筑材料，就把视界元件分区为这些材料并放入终端，这样就只会显示这些物品。

视界元件的效果是叠加的：如果你有一个橡木木板视界元件和一个圆石视界元件，两个一起放入就会同时显示木板和圆石。
