# 上色器

<ItemImage id="color_applicator" scale="4" />

上色器用于为可染色的方块涂色，例如[线缆](cables.md)、羊毛、陶瓦、玻璃和混凝土。它使用[涂料球](paintballs.md)或染料，雪球则可用于清除线缆上的颜色以及方块上的涂料球色斑。

它的能量可在 <ItemLink id="charger" /> 中补充。

上色器的行为类似[存储元件](storage_cells.md)：将其放入 <ItemLink id="chest" /> 的存储元件槽中，即可最方便地补充其中的颜料储备。

右键点击目标即可涂上所选颜色。按住 Shift 滚动鼠标滚轮即可切换颜色；也可以在没有目标的情况下右键点击来换色。

## 升级

上色器支持以下[升级卡](upgrade_cards.md)，需通过 <ItemLink id="cell_workbench" /> 插入：

*   <ItemLink id="equal_distribution_card" /> 为每种类型分配相同的元件字节空间，防止单一类型占满整个元件
*   <ItemLink id="void_card" /> 在元件已满（或在装有均分卡的该类型的已分配空间已满）时销毁插入的物品。请务必小心设置分区！
*   <ItemLink id="energy_card" /> 用于提升电池容量
