# 石英纤维

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/assemblies/quartz_fiber.snbt" />
<IsometricCamera yaw="195" pitch="30" />
</GameScene>

石英纤维用于在各个[网络](../ae2-mechanics/me-network-connections.md)之间共享电力，同时保持它们彼此独立。这让你无需在各处摆放能量接收器和供电线缆，即可为[子网络](../ae2-mechanics/subnetworks.md)供电。它也可以用来阻止线缆相互连接，不过使用不同颜色的线缆，或使用 <ItemLink id="cable_anchor" /> 会更便宜、更有效。

它们是[线缆子部件](../ae2-mechanics/cable-subparts.md)。
