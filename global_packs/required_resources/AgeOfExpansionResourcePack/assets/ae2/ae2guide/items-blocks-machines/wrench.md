# 扳手

<Row>
  <ItemImage id="certus_quartz_wrench" scale="4" />

  <ItemImage id="nether_quartz_wrench" scale="4" />
</Row>

扳手用于旋转 ae2 设备（右键点击），以及拆卸 ae2 方块（Shift+右键点击）。
可以将[子部件](../ae2-mechanics/cable-subparts.md)从线缆上取下而不破坏线缆上的其他部分
（也可以在不破坏子部件的情况下取下线缆）。

许多 ae2 方块都可以旋转，所以本指南没有提到某物可以旋转，并不代表你不能旋转它。
