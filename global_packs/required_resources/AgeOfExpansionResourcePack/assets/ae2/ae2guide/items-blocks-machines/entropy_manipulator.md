# 熵操纵器

<ItemImage id="entropy_manipulator" scale="4" />

熵操纵器可以加热和冷却物体：右键点击为加热，Shift+右键点击为冷却。它的功能不多，只能做些诸如蒸发或冻结水、将岩浆凝固成黑曜石、在世界中原位将原木冶炼成木炭、将圆石烧成石头之类的事情。

如果它对某个方块没有特定作用，就会像打火石一样工作。

它的能量可在 <ItemLink id="charger" /> 中补充。
