# 什么是应用能源2？

应用能源2（Applied Energistics 2，简称 AE2）为游戏添加了大量物流与存储相关的组件和机制。你可以用一套紧凑的 ME 网络取代堆满箱子的整个房间，而这仅仅是开始。
应用能源的设计初衷就是与其他模组协作并实现自动化。你可以搭建这样的系统：一键合成复杂配方链所需的全部前置材料（以及最终产物）；或者将某些物品的库存维持在指定数量，按需自动补货；又或者简单地在基地各处之间传输物品。
